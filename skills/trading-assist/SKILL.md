# Trading Assist

Use this skill for the secondary trading workflow.

## Objective
Improve trading decisions without overriding risk controls or stealing focus from the main YouTube business.

## Workflow
1. Identify the asset / setup / question.
2. Gather the minimum relevant market context.
3. Produce a structured view:
   - thesis
   - trigger
   - invalidation
   - size / exposure limit
   - exit plan
   - confidence
4. If any of the above is missing, return blocker / incomplete advice.

## Hard rules
- no invalidation, no trade
- no size limit, no execution suggestion
- no exit plan, no complete advice
- high-risk action requires confirmation
- trading is secondary mode, not the default business focus
