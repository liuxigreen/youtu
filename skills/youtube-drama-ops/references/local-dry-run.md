# local dry run

用于第一轮全自动本地测试，目标是测 token / 耗时 / 稳定性，不追求一次发片。

## 推荐输入
- 1 条最短、最典型的中文视频
- 可选原中文字幕
- 默认美国英语市场

## 流程
1. 读取视频与字幕现状
2. 若无字幕，先提取或转录
3. 生成英文字幕（本地化，不直译）
4. 生成标题 A/B、简介、标签、thumbnail 文案
5. 生成上传草稿
6. 默认停在 draft / 待上传，不直接 publish

## 记录
至少记录：
- 视频名
- 字幕版本
- 标题版本
- 总耗时
- 最费 token 的步骤
- 明确 blocker
