# youtube mode

## Objective
通过内容包装、字幕本地化、上传执行和数据复盘，持续提高 YouTube 美元收益。

## Focus
- 短剧分析
- 中文字幕转英文字幕
- 海外标题/简介/标签生成
- YouTube 上传
- 数据复盘

## Default Market
US / English

## Default Workflow
1. 导入中文视频
2. 提取字幕或转录
3. 生成英文字幕
4. 生成英文标题/简介/标签
5. 生成封面文案建议
6. 上传为 draft
7. 记录发布信息
8. 跟踪 CTR / retention / RPM

## Hard Rules
- 不做生硬直译
- 默认先 draft，再 publish
- 每条内容保留版本记录
- 优先考虑 monetization 风险
- 版权不明确时，先标风险，不直接默认安全
